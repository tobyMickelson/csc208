# practice problem 10

> Consider sets $$A$$ and $$B$$ with $$|A| = 14$$ and $$|B| = 21$$.
> 
> How many functions $$f: A \rightarrow B$$ are there?
> 
> How many functions $$f: A \rightarrow B$$ are injective?

## subproblem 1

there are $$14$$ elements in set $$A$$ that need to map to $$21$$ elements in
set $$B$$, therefore there are $$21^{14}$$ because there are $$21$$ choices for
each of the $$14$$ elements in set $$A$$.

## subproblem 2

for a function to be injective, each input needs to map to a unique output. this
means there are $$21$$ choices from set $$B$$ for the first element in set
$$A$$. after that, only $$20$$ elements remain. this can be simplified down to
$$\frac{21!}{7!}$$, with $$7$$ coming from $$21-14$$.
